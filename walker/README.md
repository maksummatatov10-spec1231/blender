# Странник / Wanderer

Игра-ходилка по долине: деревня, лес, горы, водопад и озеро.
Вид от первого и третьего лица, главное меню, настройки языка и графики.

Персонаж — **Mixamo Soldier** с анимациями **Idle / Walk / Run**
(файл `assets/Soldier.glb` из поставки three.js, рига и анимации Mixamo).

## Оптимизация

По условию: модели в радиусе 5 метров от игрока — «реальные»
(полная детализация + физика), остальные — только визуальные.

- В **Godot**: все твёрдые тела (дома, деревья, камни) регистрируются
  менеджером; их `CollisionShape3D` включается только в радиусе
  `REAL_RADIUS = 5 м` от игрока (`world.gd: update_lod_collisions`).
  Лес рендерится двумя LOD-ярусами через `MultiMesh`: рядом — детальные
  деревья, далеко — упрощённые (`update_tree_lod`), за туманом — скрываются.
- В **веб-версии** (three.js): коллизии работают только для объектов ближе
  6 м, трава инстансится только вокруг игрока, дальние деревья и туман
  прячут всё лишнее; графика переключается пресетами Низкая…Ультра.

## Запуск в браузере

Модули не работают с `file://`, нужен сервер:

```bash
cd web
python3 -m http.server 8080 --bind 0.0.0.0
```

Управление: WASD, мышь (зажать и вести, либо клик «Играть» для захвата),
Shift — бег, пробел — прыжок, V — вид 1/3 лицо, E — табличка, Esc — меню.
Язык и графика сохраняются в `localStorage`.

## Запуск в Godot 4.7

Проект лежит в `godot/` (`scenes/main.tscn` + скрипты в `scripts/`).
Открыть папку `godot` в редакторе Godot 4.7 и нажать F5.

Официальный бинарник редактора с GitHub Releases в этой песочнице
не скачивается (обрывается TLS на release-assets), поэтому движок
собран из исходников 4.7.2-stable:

```bash
scons platform=linuxbsd target=editor -j1 x11=no wayland=no \
      speechd=no accesskit=no debug_symbols=no optimize=none
./bin/godot.linuxbsd.editor.x86_64 --path godot --headless --quit-after 600
```

Сборка без X11/Wayland — headless-режим: импорт ресурсов и проверка
ошибок скриптов работают, отрисовка требует видеокарты.

     res://scenes/test_play.tscn
